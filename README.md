# SlayPad

This is a 12key hackpad with 1 rotay Encoder, and 3 RGB LEDs. I've used "XIAO RP2040" microcontroller in it. For the CAD I made it in two parts "Top" and "Bottom". The over all Hackpad looks came up really awsome🎀. I'm so exicted to build this!!!

Currently JLPCB has a sale discount going in it so the PCB in screenshot is $2 cheapper, but I don't know wether that dicount will be there when I'll get the grant so I added $2 extra on PCB to cover it up if I don't get dicount that that moment.
